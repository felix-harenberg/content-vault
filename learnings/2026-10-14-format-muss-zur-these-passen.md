# Das Format muss zur These passen

## Was ich gemacht habe
Formate danach bewertet, ob sie meine Position stützen oder untergraben.

## Was passiert ist (Zahlen)
Noch keine Daten. Strategisches Prinzip.

## Warum (meine Erklärung)
Ein Format wie "Tipps von Pros" funktioniert anderswo gut. Wenn meine These aber sagt, dass man kein Spezialwissen braucht, widerspricht so ein Format der eigenen Positionierung. Popularität allein reicht nicht.

## Was ich daraus mache
Vor jedem Format prüfen: Stärkt es die These oder schwächt es sie?
