# Skripte

Frameworks (Aufbau eines Skripts) und fertige Skripte von veröffentlichten Posts.

- Frameworks: `framework-<name>.md`
- Veröffentlichte Skripte: `YYYY-MM-DD-<thema>.md`, mit Link zum Post und Zahlen

## Vorlage (veröffentlichtes Skript)

```markdown
---
datum: YYYY-MM-DD
format: reel | karussell
länge: <sekunden oder slides>
post: <link>
---

# Thema

## Hook
## Skript
## Ergebnis (Zahlen)
## Was ich anders machen würde
```
