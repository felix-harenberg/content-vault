# content-vault

Strukturiertes Wissen zu Social Media Content (Instagram Reels & Karussells, Fitness/Hyrox Nische, deutschsprachig), gesammelt aus eigener Erfahrung.

Der Fokus liegt auf dem, was in der Praxis getestet wurde. Generische Tipps gibt es überall, echte Learnings mit Zahlen nicht.

## Struktur

| Ordner | Inhalt |
|---|---|
| [`learnings/`](learnings/) | Was bei eigenen Posts funktioniert hat und was nicht, mit Zahlen. Der wichtigste Ordner. |
| [`hooks/`](hooks/) | Hook-Formeln und konkrete Beispiele, inkl. Performance wenn bekannt |
| [`scripts/`](scripts/) | Skript-Frameworks und fertige Skripte |
| [`strategy/`](strategy/) | Positionierung, Zielgruppe, Persona, Content-Säulen |
| [`research/`](research/) | Fakten und Studien zu Fitness/Hyrox-Themen, immer mit Quelle |
| [`sources/`](sources/) | Zusammenfassungen von Kursen, Büchern, Videos (in eigenen Worten) |

Jeder Ordner hat ein eigenes README mit Vorlage und Index.

## Regeln

- **Eigene Worte.** Keine kopierten Kursinhalte. Zusammenfassen, einordnen, mit Quelle verlinken.
- **Belege.** Learnings mit Post-Link und Zahlen (Views, Saves, Shares, Follows). Ohne Daten ist es eine Hypothese, und wird auch so markiert.
- **Eine Datei pro Idee.** Lieber viele kleine Dateien als ein riesiges Dokument.
- **Dateinamen:** `kleinbuchstaben-mit-bindestrichen.md`, Learnings mit Datum vorne: `2026-10-14-thema.md`.
